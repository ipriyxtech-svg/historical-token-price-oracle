# 📖 About

**Historical Token Price Oracle** is a blockchain-based oracle service that provides reliable historical cryptocurrency token prices for decentralized applications (DApps).

It enables smart contracts and Web3 applications to access trusted historical price data for analytics, financial applications, DeFi protocols, and blockchain-based decision making.
